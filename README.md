# nix-setup

To setup nix based system run `./bootstrap.sh`

## Manual steps

1. On macOS, grant Accessibility permission to AeroSpace when prompted in **System Settings > Privacy & Security > Accessibility**.
2. Create two profiles under Google Chrome: `Work` and `Personal`.
3. To back up Raycast, run **Export Settings & Data** in Raycast.
4. To restore Raycast after setup, run **Import Settings & Data** in Raycast, select the saved raycast config file, enter its passphrase, and choose which categories to import.
5. Open **Karabiner-Elements** and follow its setup prompts to grant the required permissions.
